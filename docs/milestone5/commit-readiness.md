  fixes were mixed into the measurement task.

  Ignore patterns were checked with `git check-ignore`; `.gitignore` needed no changes.
- Every new public file was inspected and scanned for common private-key, API-key,
  bearer-token, email-address, user-home path and absolute workspace-path patterns.
  No candidate secrets/customer identifiers were found. Pattern scans are a useful
  check, not a cryptographic proof of secret absence.
- The only actual inputs/outputs published are authored synthetic data and its
  local model responses. GPU/CPU information is isolated in group C; original
  database fingerprints and machine-specific temporary copies stay in group B.
- Public artifacts use repository-relative links. Generic command examples use
  `.venv` paths, not a user's home directory. The runner derives its project path
  at runtime instead of embedding a developer's absolute machine path.
- The report, raw results, datasets and aggregate JSON files are intentional,
  small benchmark evidence. Dependency environments, databases and temporary
  inspection copies are unnecessary generated artifacts and must stay local.
